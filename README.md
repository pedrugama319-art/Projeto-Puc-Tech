# Projeto-Puc-Tech
- Descrição do projeto: Nosso projeto apresenta um codigo na linguagem C com o objetivo de recriar o jogo da velha, contendo funções para cada resultado
  e um menu interativo para o jogador.
- Para rodar o codigo é necessario clonar o repositorio e acessar a pasta, instalar as dependecias necessarias(compilador, GCC, extensao para C/C++, etc) e
  iniciar a aplicaçao executando o codigo em uma IDE 
- Divisão de funções: 
• Renato: Desenvolvimento da função que verifica se houve um empate a cada jogada por round
• Leopoldo: Desenvolvimento da funçao que apresenta o tabuleiro do jogo e os componentes inclusos no escopo da main utilizando as funções
• Pedru: Desenvolvimento da função que verifica se houve uma vitoria a cada jogada por round
